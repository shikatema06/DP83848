# 2026-08-10

## IAP A/B 槽升级改造 - Bootloader 启动与 TFTP 迁移（完成）

本轮完成 IAP 在线升级重写的剩余迁移工作，App 与 Bootloader 均已编译通过。

### 完成的改动

1. **`Bootloader/tftp_server.c`**：改造为写入备用槽
   - WRQ 时用 `iap_slot_get_spare()` 选备用槽，写地址改为 `iap_slot_start_addr(Current_Slot_ID)`。
   - 最后一个 DATA 包处理改为：读 expected_crc → 计算 CRC → 与 expected_crc 交叉比对 → `iap_slot_mark_new()` → `iap_slot_commit()` → `NVIC_SystemReset()`。
   - 所有成功/失败路径汇聚到单一 `NVIC_SystemReset()` 出口。

2. **`Bootloader/bootloader_main.c`**：启动决策迁移到 iap_slot
   - `jump_to_app()` 改带地址参数，`APP_START_ADDR` 宏删除。
   - `main()` 用 `iap_slot_init()` + `iap_slot_get_active()` + `iap_slot_start_addr()` 决定启动。

3. **App 侧 `Core/Src/tcp_echoserver.c`**：`CMD_ENTER_BOOTLOADER` 改为写 `BOOT_REQUEST_UPGRADE` 到 `BOOT_REQUEST_ADDR` 再 `NVIC_SystemReset()`，不再直接跳转。

4. **新建 `Core/Inc/boot_request.h`**：Bootloader 与 App 共享的 BOOT_REQUEST 地址/魔数定义（`0x0800FFF8`）。

5. **编译修复**：
   - `flash_if.h` 补 `FLASH_If_Init()`、`FLASH_Get_Sector()` 声明（之前缺声明导致 C99 隐式声明报错）。
   - `Core/Src/main.c` 向量表符号从 `__Vectors` 改为 GCC 启动文件导出的 `g_pfnVectors`（修复 undefined reference to `__Vectors`）。
   - `LWIP/Target/ethernetif.c` 补 `#include "gpio.h"` 消除 `MX_GPIO_PhyReset` 隐式声明警告。
   - `CMakeLists.txt` 顶层加 `add_subdirectory(Bootloader)`，`Bootloader/CMakeLists.txt` 加 `add_executable(DP83848_BOOT)` 并加入 `iap_slot.c`。
   - `Bootloader/CMakeLists.txt` 给 `DP83848_BOOT` 单独设 `-Os` 优化，使 48KB Flash 容量足够（46.9KB/48KB，Debug 用 -O0 会溢出 1.5KB）。

### 构建结果
- App `DP83848.elf`：FLASH 92KB/1MB ✅
- Bootloader `DP83848_BOOT.elf`：FLASH 46.9KB/48KB ✅
- code-explorer 扫描确认所有编译目标无旧 `BOOT_VALID_*` / `USER_FLASH_FIRST_PAGE_ADDRESS` / `APP_START_ADDR` 残留。

### 遗留/注意
- Bootloader 链接有 memory region redeclaration 警告（工具链全局 `-T` 与 BOOT `-T` 都定义 RAM/CCMRAM/FLASH），无害，链接器实际使用 BOOT 脚本。
- 升级流程改为：App 写 BOOT_REQUEST_UPGRADE → 软复位 → Bootloader 冷启动进 TFTP → 收固件写备用槽 → mark_new/commit → 复位 → 新 active 槽启动。
